# CubeMX Regeneration Checklist

When regenerating code from `mult-output-power.ioc`, verify these items remain correct.

## ADC (`Core/Src/adc.c`)

| Parameter | Required value |
|-----------|----------------|
| `DiscontinuousConvMode` | DISABLE |
| `DMAContinuousRequests` | ENABLE |
| `ScanConvMode` | FORWARD |
| `ContinuousConvMode` | DISABLE |
| Channel order | CH0 (PA0) -> CH5 (PA5) -> VREFINT |

## USER CODE to preserve

### `Core/Src/adc.c` (USER CODE BEGIN 0)

```c
DMA_HandleTypeDef hdma_adc;
```

### `Core/Src/adc.c` (ADC1_MspInit USER CODE)

- DMA1 Channel1 init
- `__HAL_LINKDMA(adcHandle, DMA_Handle, hdma_adc)`
- `HAL_NVIC_EnableIRQ(DMA1_Channel1_IRQn)`

### `Core/Inc/adc.h`

```c
extern DMA_HandleTypeDef hdma_adc;
```

### `Core/Src/stm32f0xx_it.c` (USER CODE BEGIN 1)

```c
void DMA1_Channel1_IRQHandler(void)
{
  HAL_DMA_IRQHandler(&hdma_adc);
}
```

## Application layer (not generated by CubeMX)

- Sampling: `hardware/hw_adc_sample.c` (async DMA)
- Config page flash: `0x08007C00` (last 1 KB page) used by `app/app_storage.c`

## After regenerate

1. Compare `adc.c` with this checklist
2. Build Release: `cmake --build build/Release`
3. Verify voltage reading with a multimeter
